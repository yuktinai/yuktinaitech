Why teams use it

Clean monetization tooling without extra app complexity.

  • Initialize quickly with a small Android integration surface.
  • Track monetization events safely through SDK helpers.
  • Read user segment state for ad, subscription, and hybrid experiences.
  • Keep monetization behavior centralized through the SDK instead of custom app-side plumbing.

Step 1

Add the dependency

Use `mavenCentral()` in your Android project repositories and install the current stable release.

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}

dependencies {
    implementation("com.yuktinai:amos-sdk:1.0.1")
}

Step 2

Initialize the SDK

Provide your app API key, app identifier, and user identifier at session start.

Monetization.init(context, "API_KEY", "APP_ID", "USER_ID") {
    val state = Monetization.getState()
    val segment = state.userSegment
    val allowedEvents = state.allowedEvents
}

Step 3

Track safely

Use the SDK helpers for cleaner event tracking in the host app.

val tracked = Monetization.trackEventIfAllowed("ad_watched")

if (Monetization.isEventAllowed("paywall_click")) {
    Monetization.trackEvent("paywall_click")
}

Integration flow

What the app team does

  1. Your app initializes the SDK with `API_KEY`, `APP_ID`, and `USER_ID`.
  2. Your app reads SDK state after initialization when needed.
  3. Your app tracks events through the SDK helpers during the session.
  4. Your app ends the session with `Monetization.endSession()` when appropriate.
  5. The SDK handles the underlying service communication internally.

What to prepare

Before the app team starts

  • A valid AMOS `API_KEY` and `APP_ID`.
  • An agreed user identifier strategy for the host app.
  • Android Internet permission in the app manifest.
  • A clear place in the app where segment state will be consumed.
